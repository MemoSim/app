write

write 2.0

write value

This command will output value, which can be a number, string, list, boolean, or nobody to the Command Center, notfollowed by a carriage return (unlike printand show).

This agent is not printed before the value, unlike show. Its output also includes quotes around strings and is prepended with a space.

write "hello world"
=>  "hello world"

See also print, show, type, output-write, and Output (/programming guide).
